# The Nexum — Foundation Starter

**An UmBrage Creation**

This is an independent, Android-first static PWA foundation for The Nexum.
It does not connect to UmBrage and contains no credentials, API keys, or
production integration code.

## Current scope
- Independent application shell and visual system
- Modular workspace navigation
- Responsive layout for mobile and desktop
- Placeholder screens for the approved Nexum workspaces
- Documentation for architecture, boundaries, security, and future integration

## Not included yet
- Authentication or cloud database
- AI provider integrations
- Image/video generation APIs
- File uploads or permanent asset storage
- UmBrage data connection
- Social publishing or messaging integrations

These are intentionally deferred until their requirements and permissions
are designed and reviewed.

## Run locally
Open `index.html` in a browser. For PWA/service-worker testing, use HTTPS
hosting such as GitHub Pages.

## Deploy as a separate GitHub Pages project
1. Create a NEW repository named `the-nexum` (or another name you choose).
2. Upload the contents of this folder to the repository root.
3. Enable GitHub Pages from the repository's main branch and root folder.
4. Open the published URL and test on Android Chrome.

Do not upload this project into an UmBrage repository or replace any existing
UmBrage files.

## Current build status
Foundation scaffold only. The screens are navigation placeholders, not
completed product features. No production service has been connected.
