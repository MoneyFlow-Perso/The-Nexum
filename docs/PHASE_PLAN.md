# Development phases

| Phase | Scope | Exit condition |
|---|---|---|
| 0 | Product boundaries, architecture, security and project scaffold | Independent foundation approved |
| 1 | Application shell, navigation, homepage and responsive workspaces | Stable Android/desktop shell |
| 2 | Brand Intelligence and knowledge management | Brand rules can be saved and reused |
| 3 | Creative Director and Quick Campaign | Campaign brief generated from discussion or garment input |
| 4 | Visual, Video and Content Studios | Standard social kit can be produced and saved |
| 5 | Growth Studio and Campaign Library | Complete growth kit and reusable campaign library |
| 6 | UmBrage Level 2 integration | Approved data can be read safely without write access |
| 7 | QA, security, usability and release | Critical tests pass and rollback plan exists |

Planning estimate:
- Usable MVP: approximately 4–6 weeks
- First full release: approximately 8–12 weeks
- Cautious schedule: approximately 12–16 weeks

These are planning estimates, not guaranteed dates. External provider access,
integration review, testing and available build time can change the schedule.
